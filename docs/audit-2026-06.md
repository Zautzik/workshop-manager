# Workshop Manager — Product & Code Audit (June 2026)

> **Method.** Drove a real headless Chrome session against the running `localhost:3000`
> (dev session auto-authenticates as admin "Dev"), captured **63 screens across every
> route**, and cross-referenced each against the single source of truth in
> [`src/lib/navigation.ts`](../src/lib/navigation.ts) and the page components. Every
> finding is anchored to a screenshot and/or a `file:line`.
>
> **Scale.** 66,889 LOC (TS/TSX) · 7 modules · ~54 leaf screens.

---

## Executive verdict

The bones are strong — Comercial's CRM, the WhatsApp capture queue, the FSSC Calidad
module, and the Diagnostics page are real, sellable assets. But the app is **mid-refactor
and it shows**: the same views exist in two generations, business-critical cost data lives
in the browser, the analytics layer is built but unwired to data, and most working pages
lead with secondary noise instead of the task. None of this is fatal — it's a tightening
job, not a teardown.

Two headlines: **~10% of the codebase is removable with zero feature loss**, and **the one
number we price jobs on currently lives in a browser cache.**

## Part A — Structural findings (the patterns that repeat)

**A1 · Two generations of "Operaciones" on top of each other.**
`Tablero` ([kanban/page.tsx:9](../src/app/operaciones/kanban/page.tsx)) and `Planta`
([planta/page.tsx:14](../src/app/operaciones/planta/page.tsx)) mount the legacy
`WorkflowDashboard` (1,609 LOC) which carries its **own internal tab bar of 11 views**
([WorkflowDashboard.tsx:34-54](../src/page-components/WorkflowDashboard.tsx)). Meanwhile
`En Proceso`, `Hoja de Prod.`, `Archivo OT`, `Planificación` are new standalone pages.
Gantt, Calendar, Plan Semanal, Clientes, Turnos each exist **twice**.

**A2 · Three navigation surfaces for the same destinations.**
Sidebar ([AppShell.tsx:59-72](../src/components/AppShell.tsx)) + hex module-landings +
(for Tablero/Planta) the WorkflowDashboard tab bar. The first two are intentional mirrors;
the third is leftover and is the one that confuses.

**A3 · Business-critical data in `localStorage`.**
The cost catalog persists to the browser under `workshop_cost_center`
([CostCenterManager.tsx:47-59](../src/components/financial/CostCenterManager.tsx)) —
per-device, not shared, erased on cache-clear.

**A4 · Naming drift: the label you click ≠ the title you land on.**
`Costos → "Centro de Costos"`, `Archivo OT → "Producción"`, `Tablero → tab "Kanban"`,
`Plan & Órdenes → "Órdenes de Trabajo"`, and `Modo Planta` vs `Planta` (two different
tools, near-identical names).

**A5 · Role visibility drifts from page guards (painted doors).**
Home shows `Operaciones` to `technician` ([HomeDashboard.tsx:48](../src/page-components/HomeDashboard.tsx))
but the module excludes them ([navigation.ts:106](../src/lib/navigation.ts)).
`Inventario`/`Compras` pages are `admin`-only but their group shows to managers.

**A6 · An app-wide runtime error.** The Next.js "1 Issue" dev badge appears on most pages
(Home, Calidad, Equipos, Personas, Floor…). One debugging pass; may share a root cause with
Floor's "Desconectado" realtime and the page that won't render headless (`/equipos/ejecucion`).

**A7 · Inconsistent data quality.** Polished real data in Clientes, Inventario, Costos,
Máquinas; junk seed elsewhere (`saad`, `ffdfs`, `22123` OT chips; `fdf / Press`, `Ñaño` workers).

**A8 · Four machine-status vocabularies** for the same fleet:
`En operación/En espera` (Máquinas) · `En marcha/Inactiva` (Carga) · `idle/running`
(Diagnostics) · `Inactiva/En marcha/Mantenimiento/Fuera de línea` (Dashboard TPM).

**A9 · Inconsistent headcounts.** Empleados **23** (Diagnostics) vs **0** (Costo Laboral)
vs **22** workers (Rendimiento) vs Operarios **43**. The empleado/operario model is ambiguous.

**A10 · i18n leaks.** English strings surface across Equipos/Analítica
(`New Checklist`, `Add Machine Cost Data`, `Month`, `Difference`, `Recommendation`,
`Average performance rating`, `idle/running`). Validates the `ot-i18n-types-hardening` work.

**A11 · Analytics unwired.** Dashboard charts, Rentabilidad, Tendencias, and both roll-ups
are empty — the analytics promise has no data pipeline behind it yet.

## Part B — The three deep-dives

**B1 · Analítica → "Centro de Costos" / "Costo Promedio".**
Live value observed: **$13.744 "por unidad"**, computed by averaging paper ($950–3.500/kg)
with ink, labor and "click" costs and dividing by count
([CostCenterManager.tsx:168-181](../src/components/financial/CostCenterManager.tsx)) — a
meaningless blended figure. The catalog also can't represent the same SKU bought in
different lots at different prices (couché 100 g is one hand-typed line). The average that
matters — **weighted moving average per SKU from real purchases** — does not exist.
→ Reclassify the catalog as configuration; build true costing in
[`/analitica/rentabilidad`](../src/app/analitica/rentabilidad/page.tsx) (which already has
Márgenes / Estimado vs Real / Costos Reales tabs, currently empty).

**B2 · Modo Planta vs Planta vs Tablero.**
`Tablero` is a rich hexagonal **workflow board by stage** (Diseño→Compras→Corte&Impresión→
Acabados→Terminación→Despacho). `Modo Planta` ([floor/page.tsx](../src/app/operaciones/floor/page.tsx))
is a flat **4-column status board** showing the same OTs with **less** information, and its
only exit button pointed at a dead `/workflow` route. `Planta` is the drag-drop workstation
scheduler. → Make Modo Planta a *present-on-big-screen* mode of the Tablero; rename Planta.

**B3 · Abastecimiento (Inventario + Compras + Proveedores).**
`Proveedores` is a stub ("Módulo en desarrollo"
[proveedores/page.tsx:19-23](../src/app/operaciones/proveedores/page.tsx)); `Compras`
already claims "y proveedores"; all three are already grouped. → One workspace with tabs
(Stock · Compras · Proveedores) fixes the stub and the role drift in one move.

### C2 · Legacy `ot-wizard` — *partial* dead code

Generated shadcn components never imported: `aspect-ratio, avatar, breadcrumb, carousel,
context-menu, drawer, form, hover-card, input-otp, menubar, navigation-menu, pagination,
radio-group, resizable, sidebar, toggle-group`.

### C5 · Dead / transitional routes
- `/workflow` — referenced by Modo Planta's exit but no such route exists (**fixed**).
- `/supply`, `/supervisor` — redirect shims to `/operaciones`; remove once unlinked.
- `/equipos/programa`, `/checklists`, `/stats`, `/predictive` — exist but not in primary nav.

> **Net:** ~6,000–7,000 LOC (~10%) removable. Safety: delete in batches gated by
> `npm run typecheck` + `next build`.

## Appendix — Per-screen findings (full sweep)

Legend: ✅ strong · ⭐ valuable but empty/unwired · ⚠️ problem · 🧪 junk/seed data.

### Home & entry
- **`/home` — Living Home** ✅ — 7-hex honeycomb with live organ vitals (Operaciones *Validadas 93%*, Analítica *Salud 73*, Equipos *Uso 47%*). On-brand. Hero "¿Cómo puedo ayudarte hoy?" promises a command bar the static menu doesn't deliver.
- **`/login`** — renders "Ya iniciaste sesión" because a dev session auto-authenticates as admin "Dev".

### Operaciones
- **`/operaciones` (landing)** ⚠️ — 12 tiles across 4 clusters; busy; ambiguous decorative center-hex.
- **Tablero `/operaciones/kanban`** ✅🧪 — rich hex workflow board by stage; junk OT chips.
- **En Proceso `/operaciones/ordenes-en-proceso`** — standalone `OrdenesEnProceso`. (Captured.)
- **Hoja de Prod. `/operaciones/hoja-produccion`** — standalone `HojaProduccion`. (Captured.)
- **Archivo OT `/operaciones/production`** ⚠️ — mounts `OTRetrievalSystem`; H1 says "Producción" (label drift).
- **Modo Planta `/operaciones/floor`** ⚠️ — flat 4-column status board; shows less than Tablero; exit pointed to dead `/workflow` (**fixed**); realtime "Desconectado"; "1 Issue" error.
- **Estación `/estacion`** — QR badge clock-in kiosk (fullscreen). (Captured.)
- **Planta `/operaciones/planta`** ⚠️ — workstation scheduler (WorkflowDashboard `layout`); a repeating per-date **"Turno Día/Tarde"** strip on top is noise; name collides with Modo Planta.
- **Planificación `/operaciones/calendar`** ✅ — 4 tabs (Cronograma/Máquinas/Calendario/Semanal); good recent 3→1 consolidation.
- **Inventario `/operaciones/inventario`** ⚠️ — 3 summary cards then a full-viewport "Alertas de stock bajo" list (13 items) above the actual table; you scroll a whole screen to reach the SKUs.
- **Compras `/operaciones/compras`** — `PurchasesManagement`; subtitle "y proveedores". (Captured.)
- **Proveedores `/operaciones/proveedores`** ⚠️ — stub "Módulo en desarrollo".
- **WhatsApp `/operaciones/whatsapp`** ⭐ — capture/approval queue (Pendientes/Historial/Entrada Manual; En producción 55; Confianza prom. 0%). The data spine, buried as one tile.

### Calidad — *most coherent module* ✅
- **`/calidad` (landing)** ✅ — single clean group: Expediente · Ciclo de OT · Simulacro Retiro · Retención · Certificaciones (FSSC 22000). Detail pages captured.
- Note: "Certificaciones" also exists in Personas → disambiguate.

### Comercial — *best-built screen* ✅
- **Clientes `/comercial/clientes`** ✅ — real CRM (11 clients, RUT, contacto, payment terms 15/30/45/60 días, CRUD). The quality bar to copy. Also exists as a WorkflowDashboard tab → consolidate.

### Personas — sane structure
- **`/personas` (landing)** — Personal (Empleados, Asistencia, **Contratos** renders greyed/muted → verify stub) + Compensación & Carrera (Retribución, Habilidades, Capacitación, Certificaciones, Incentivos). Detail pages captured.
- **Retribución/Nómina** duplicated as Analítica→Costo Laboral (intentional roll-up).

### Equipos — *over-fragmented: ~10 routes for 17 machines / 3 PM orders*
- **Máquinas** ✅ — 17/17 card grid, real fleet, QR + kW + status (`En operación/En espera`). Delivery vehicles filed as machines.
- **Plan & Órdenes `/ordenes`** — 3 PM orders; H1 "Órdenes de Trabajo" (drift).
- **Programa `/programa`** ⚠️ — PM task templates; "Tiempo semanal 0 min" (no time estimates); **not in nav**.
- **Checklists `/checklists`** ⚠️ — PM checklists; English "New Checklist"; **not in nav**; duplicates Programa.
- **Stats `/stats`** ⚠️ — mini-dashboard (Total 3 / 33% cumplimiento); **not in nav**; duplicates Órdenes+Historial.
- **Historial** — completed-PM timeline (1); third view of the same 3 orders.
- **Carga & Utilización** — per-machine load (all 0h); status `En marcha/Inactiva`; overlaps Predictive.
- **Predictive `/predictive`** ⚠️ — service-interval counters (0/500.000 hojas); **not in nav**; overlaps Carga.
- **Economía** ⭐ — machine cost vs **tercerización** + recommendation (a real press decision); empty + half English.
- **Ejecución** ⚠️ — would not render headless (hung); runtime/perf flag.

### Analítica — *built shells, mostly unwired*
- **Dashboard** ⭐ — exec KPIs (Utilización 47% OEE, Eficiencia 85%); "-100.0%" delta looks buggy; charts empty. Second exec overview alongside Home.
- **Rentabilidad por OT** ⭐ — Márgenes / Estimado vs Real / Costos Reales (empty). The right home for per-OT costing.
- **Tendencias** ⚠️ — empty; time axis reads "may 26 → feb 26" (backwards).
- **Rendimiento** 🧪 — worker stat grid; all zeros; junk ("fdf / Press", "Ñaño"); English "Average performance rating".
- **Economía Equipos** ✅ — roll-up "detalle en Equipos → Economía" (correct pattern; thin/empty).
- **Costo Laboral** ✅ — roll-up "detalle en Personas" (Empleados 0 despite 22 → not wired).

### Administración — *solid, but a non-functional Settings facade*
- **Usuarios** ✅ — 2 users; `cubensista@gmail.com` has no role; doubled heading.
- **Notificaciones** — inbox (empty); accent typos ("busqueda", "gestion"); 3rd notification surface.
- **Configuración del Sistema** ⚠️ — handsome grid but every "Config" button is a placeholder (footer admits it); duplicates sidebar theme/lang toggles.
- **Integraciones** — ERP/pagos connector form (empty); "Integracion" missing accent.
- **Diagnósticos** ⭐ — genuinely useful (DB online 647 ms, tabs Salud/Webhooks/Seguridad/Logs/Coherencia); machine status `idle/running` (English).
