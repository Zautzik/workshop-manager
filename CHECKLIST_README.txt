🚀 QUICK START (5 MINUTES)

1. Apply Database Migration
   → Copy migration to Supabase or run: npx supabase migration up

2. Navigate to Checklist Editor
   → http://localhost:3000/maintenance/checklists

3. Create Your First Checklist
   → Click "New Checklist" → Fill form → Click Create

4. Add Items
   → Fill form → Click "Add Item" → Repeat

5. Save & Print
   → Click "Save Checklist" → Preview → Print
